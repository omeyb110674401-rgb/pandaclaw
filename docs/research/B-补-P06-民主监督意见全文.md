# B-补-P06 · 民主监督意见全文的程序条款

> 任务卡来源：《B-政协制度-后续调研方案.md》P0-6。执行方式：《中共中央办公厅关于加强和改进人民政协民主监督工作的意见》（**中办发〔2017〕13号**）全文逐字读取（海口政协转载，六部分完整）＋北京市政协转载关键句一致性抽查。
> 结构：一、重要意义和总体要求；二、监督主要内容（8 项）；三、监督形式（5 种）；四、工作程序（4 步）；五、工作机制（4 项）；六、党的领导（3 条）。

## 一、事实结论

### 问题 1：监督议题如何提出（第四部分「规范工作程序」第（一）条，逐字）

「人民政协民主监督议题**可由党委和政府提出，也可由政协广泛征求党派团体、政协界别、专门委员会、政协委员、党政部门等各方面意见提出**。充分协商后，由政协办公厅（室）汇总提出建议，提交政协主席会议研究，其中重点监督议题纳入政协年度协商计划，**征求政府意见后，报党委讨论确定**。」

→ 议题双来源（党委政府交办 / 政协自主征集）；审定链＝办公厅汇总→主席会议研究→重点议题纳入年度协商计划→征求政府意见→**报党委讨论确定**。与 B-P0-4 年度协商计划机制完全咬合。

### 问题 2：监督意见的报送对象与办理反馈要求（第（三）（四）条，逐字要点）

- **报送**：「政协运用会议监督意见报告、视察监督报告、专项监督报告、提案、社情民意信息等形式，及时向党委和政府及有关方面报送开展民主监督形成的意见建议。**重点监督意见根据需要由政协主席会议研究审议后报送**。」
- **办理**：「对于政协会议监督意见报告、视察监督报告、专项监督报告等，**党委和政府应专题研究，或交相关部门办理**。政协提案、社情民意信息中的监督性意见，按规定程序办理。**党政督查部门要加强对政协民主监督意见办理情况的督查**。」
- ⚠️ **否定性结论**：全文**没有**类似提案办理「5 个月/3 个月书面答复」的时限语义；监督意见办理走「专题研究或交部门办理＋督查部门督查」，反馈要求见第五部分机制条款而非程序条款。

### 问题 3：监督成果运用与办理反馈机制（第五部分第（三）条「办理反馈机制」，逐字）

「办理单位应**及时以书面、会议通报等形式反馈**政协民主监督意见办理、采纳和落实情况。政协主席会议或常务委员会会议根据需要，**听取重点监督意见办理情况通报**。政协应将办理回复情况通报参加监督的有关单位和政协委员。政协常务委员会向全体会议报告工作时，应将全年民主监督工作开展情况和监督意见办理回复情况作为重要内容。」

→ 反馈闭环＝办理单位书面/会议通报反馈 → 主席会议/常委会听取重点通报 → 向监督参加者反向通报 → 常委会工作报告年度兜底。配套还有：知情明政机制、协调落实机制（党委、政府、政协三家办公厅会商）、权益保障机制（「对于阻挠政协委员参加民主监督，甚至进行压制、打击和报复的，应依纪依法追究责任」）。

### 问题 4：五种监督形式的组织细节（第三部分，逐字要点）

| 形式 | 组织规则 |
|---|---|
| 会议监督 | 大会发言增加监督性内容比重；全会视情安排界别小组（联组）专题讨论监督性议题；常委会/主席会议/专题协商会/对口协商会等安排一定数量监督性议题；可邀请负责同志到会互动 |
| 视察监督 | 「**根据每次监督任务组织委员视察团**」——视察团按任务一次性组建；听取介绍、实地察看、座谈讨论，「着重发现工作中的问题和不足」，与负责同志交换意见后提批评建议 |
| 提案监督 | 重点提案中**应有民主监督性提案**；此类提案「由党委办公厅（室）、政府办公厅（室）、政协办公厅（室）共同交有关部门办理」，党政及政协负责同志加强督办；推进内容和办理情况公开，开展提案办理评议 |
| 专项监督 | 围绕法律法规实施和重要工作落实确定专项监督议题，由政协办公厅和专门委员会组织力量开展监督性专题调研，「深入一线**明察暗访**」，必要时应持续跟踪监督 |
| 其他形式 | 调查检查听证吸收委员参加；「政协可应有关部门邀请，**推荐特约监督员或组织民主监督小组**」；发挥社情民意信息、委员来信来访、委员举报、民主评议作用 |

### 监督内容八项（第二部分，备查）

宪法法律实施／大政方针重大改革重要决策贯彻执行／规划计划落实与财政预算执行／群众切身利益问题解决落实／国家机关及工作人员遵纪守法作风反腐／**提案建议案和其他重要意见建议办理情况**／参加单位贯彻统战方针遵守章程执行决议／党委交办其他事项。（与第一轮新华社电摘要一致，本轮升级为原文核验。）

## 四、对协议条款/模板的影响判断

1. **M17（询问通道与监督边界）**：现实依据充分——政协侧监督被明确定性为「**协商式监督**」（意见第一条），其刚性约束来自「党委和政府应专题研究或交部门办理＋党政督查部门督查」，而**非**人大质询式的强制答复义务；协议中 cppcc 角色的「监督产出」（监督报告类文书）不应赋予 npc 质询同等的强制答辩时限，二者语义区分获得 A 级出处。
2. **R2（npc 质询的「监督」语义）**：条文现实出处段落可更新为「中办发〔2017〕13 号第四部分」；监督议题进入年度协商计划的机制与红线 2 表决前置门同构。
3. **二次答辩（M3/H6）背书强度**：办理反馈机制的「书面、会议通报等形式反馈＋主席会议/常委会听取重点通报」可作为系统内「监督意见→被询问方回应→合议机构听取通报」链条的现实原型；但注意现实中反馈是「及时」而非限期——协议若设硬时限属改造，需标注。
4. **模板素材**：四种报告文书名（会议监督意见报告/视察监督报告/专项监督报告/提案、社情民意信息）＋特约监督员、民主监督小组两种角色装置进入身份库与公文模板储备；未尽事项 15（特约监督员制度）已部分覆盖（选派机制＝「应有关部门邀请推荐」）。
5. **视察团组建规则**：「根据每次监督任务组织委员视察团」回答了 P1-6 的部分问题（按次组建、任务导向），团长产生等细则仍留待 P1-6。

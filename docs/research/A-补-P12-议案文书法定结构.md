# A-补-P12：议案文书的法定结构

> **任务卡**：A 线 P1-2｜**服务条款**：M4（opinion-\* 准入标准的条文化）
> **证据状态**：全国层面《全国人民代表大会代表议案处理办法》（2005）存在性有官方新闻多源确认；要素细节以省级人大办法官方全文（江苏等）＋多个人大官网政策问答交叉。

## 结论速览

1. **三件套要件「案由、案据、方案」**：「法律对人大代表提出议案有哪些基本要求？」类官方问答在多地人大官网长期在载且口径一致：议案应当**写明案由、案据和方案**——案由＝议题名称；案据＝理由依据；方案＝解决问题的具体办法（条文层面通说系代表法及地方组织法相关要求；本轮未获逐字条文命中，条号标注待终核）。
2. **一事一案＋范围限定**：代表议案应当**一事一案**；内容必须**属于本级人民代表大会职权范围**（上海市人代会文件汇编逐字快照：「三、代表提出议案的内容，应当属于市人民代表大会职权范围」；江苏省级办法官方全文同口径）。全国层面即限于宪法第六十二条规定的大会职权。
3. **联署门槛（一手，S2/P0 批已录）**：一个代表团或者三十名以上的代表联名（大会议事规则；常委会轨十名组成人员）。议案应在规定截止时间前提出并附联名签署。
4. **处理办法体系**：全国人大常委会办公厅 2005 年出台《全国人民代表大会代表议案处理办法》（5 个配套工作文件之一），核心要求包括规范交办承办、认真吸纳提议案人的合理意见（央视/新浪新闻快照）；省级普遍制定本区域办法（江苏、南通、大同等多部全文在载），构成「全国办法定框架＋省级办法细化」的两级文书规范。
5. **不列入议程的去向**：主席团决定不列入会议议程的议案，交有关专门委员会审议或按建议办理（与 S8/M4 的退回机制同构）。

## 样本解剖：opinion-\*（议案体）的字段映射

| 现实要件 | 出处等级 | PandaClaw opinion-\* 对应 |
|---|---|---|
| 案由 | 多地官网问答交叉 | `title`（议题名，动宾短语） |
| 案据 | 同上 | `grounds`（理由＋依据引用） |
| 方案 | 同上 | `proposal`(具体可操作措施清单——M4「空泛无建议→退回」的现实锚点) |
| 一事一案 | 省级办法全文＋问答交叉 | M4 已采纳（红线：一文一事的同源原则） |
| 职权范围 | 市级文件汇编逐字＋办法全文 | 准入校验「超出议题范围→退回重提」（M4 第三条负面清单） |
| 联署名单 | 一手（议事规则） | `signatures[]`（≥门槛数） |

## ⚠️ 推翻性发现核查声明

**无推翻性发现，一处等级声明**：「案由、案据和方案」的表述本轮以 ≥3 个独立人大官网问答交叉采信，但**未取得法律正文的逐字命中**（代表法第九条之说的条号待 flk 终核）；M4 的三条负面清单裁决不受影响，属加固性补充。

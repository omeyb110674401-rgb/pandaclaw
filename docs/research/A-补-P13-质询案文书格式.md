# A-补-P13：质询案文书与答复函格式

> **任务卡**：A 线 P1-3｜**服务条款**：M17（inquiry-\* 格式）、M3（reply-\* 格式）
> **方法**：沿用 P0 批已取得的两轨质询章一手条文（A-补-P02）＋本轮多源快照补充实务格式指引。政府站点不作浏览器直抓。

## 结论速览

1. **质询案法定必填三要素（国家层面一手条文）**：「质询对象、质询的问题和内容」。大会轨＝《全国人民代表大会议事规则》（2021 修正）第四十九条；常委会轨＝《各级人民代表大会常务委员会监督法》（2024 修正）第五十一条（两轨逐字同构）。
2. **地方规范普遍升级为四要素**：在三要素之外增加「**要求**」，如重庆市实施代表法办法第十一条「质询案应写明质询的对象、问题、内容和要求」（快照级，worldlii 法规库收录）。实务写作指引还建议写明**事实与理由**（四川人大、湖北人大探讨文章，学理线索级）。
3. **书面答复函的硬性格式要素（一手条文）**：受质询机关书面答复的，「受质询机关的负责人应当签署」（大会轨＝议事规则第五十条第四款；常委会轨＝监督法第五十四条）。签署人是格式有效性的法定要件。
4. **答复方式双通道＋程序附随义务**：口头答复＝负责人到主席团会议／专委会会议／有关代表团（常委会轨：全体会议、联组会议或者有关专门委员会会议）答复，提质询方有权列席发表意见；书面答复＝负责人签署后由主席团（常委会轨：委员长会议/主任会议）决定印发。答复情况须向主席团报告（大会轨第五十条第三款）。

## 样本解剖：inquiry-\* 文书的现实字段映射

| 现实要素 | 出处等级 | PandaClaw inquiry-\* 模板对应 |
|---|---|---|
| 质询对象（受质询机关名称） | 一手（议事规则49条/监督法51条） | `target` 字段（必填，枚举到机构粒度） |
| 质询的问题 | 同上 | `question` 字段（必填，主题句） |
| 质询的内容 | 同上 | `content` 字段（必填，事实与具体所指） |
| 要求（期望的处理） | 快照级（重庆市办法11条＋多地同构） | 可选字段 `demand`；模板注释标注「国家法未强制、地方规范通行」 |
| 事实与理由 | 学理指引级（hppc/scspc 探讨） | 不设独立必填字段，并入 `content` 写作指引 |
| 联署门槛（30 名代表或代表团 / 常委会组成人员 10 人以上） | 一手（议事规则48条/监督法51条，S2/P02 已录） | 准入校验参数（已有） |

## reply-\*（答复函）格式要点

1. 必备署名：受质询机关**负责人签署**——协议 reply-\* 卡片应保留「签发人＝机关负责人」字段，不能降格为一般承办人员。
2. 形式选择权在主席团/委员长会议决定的答复形式（口头或书面），答复函应注明本次采用的答复形式。
3. 不满意救济衔接（M3 二次答辩）：大会轨无过半数门槛（提质询的代表或代表团即可提出要求，主席团决定）；常委会轨需提质询案组成人员过半数＋委员长会议或主任会议决定（监督法53条）。二次答复仍受同一格式约束。

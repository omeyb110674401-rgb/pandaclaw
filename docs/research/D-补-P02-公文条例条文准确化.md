## 四、核对表 C：行文规则条款号（第四章第十三至十七条）

| 条款 | 内容要点 | 报告引用核对 |
|---|---|---|
| 第十三条 | 行文应当确有必要，讲求实效，注重针对性和可操作性 | ✅ |
| 第十四条 | 行文关系按隶属关系和职权范围确定；一般不得越级行文，特殊情况越级的应当同时抄送被越过的机关 | ✅ |
| 第十五条 | 上行文六项规则：（一）原则上主送一个上级机关、不抄送下级机关；（二）部门向上级主管部门请示报告重大事项经本级党委政府同意或授权；（三）不得原文转报下级请示；（四）**请示应当一文一事，不得在报告等非请示性公文中夹带请示事项**；（五）不得以本机关名义向上级机关负责人报送公文、不得以本机关负责人名义向上级机关报送公文（除直接交办）；（六）双重领导抄送另一上级 | ✅ C 报告借鉴点 2 引"第十五条第四项"正确 |

## 五、GB/T 9704—2012 版头／主体／版记划分（元信息块依据）

原文（7.1）：「公文首页红色分隔线以上的部分称为**版头**；公文首页红色分隔线（不含）以下、公文末页首条分隔线（不含）以上的部分称为**主体**；公文末页首条分隔线以下、末条分隔线以上的部分称为**版记**。」页码位于版心外。

版头六要素＝份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人；主体九要素＝标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注、附件；版记＝分隔线＋抄送机关＋印发机关和印发日期。（详见 C-补-P01 数值核对。）

## 六、`PC-{类型字}〔年份〕{序号}号` 文号校准结论

对照 GB/T 9704—2012 第 7.2.5 条＋条例第九条第五项＋真实样本（国办发〔2024〕44 号、黔府办发〔2025〕1 号，见 C-补-P01 第四节）：

| # | 检查点 | 结论 |
|---|---|---|
| 1 | 年份四位全称＋六角括号〔〕 | ✅ 合规（且另有 GB/T 15834—2011 4.9.3.4 明文背书：「标示公文发文字号中的发文年份时，可用六角括号」，示例"国发〔2011〕3号文件"） |
| 2 | 序号不加「第」、不补零、阿拉伯数字后加「号」字 | ✅ 合规 |
| 3 | 序号与「号」之间的空格 | ⚠️ 校准：渲染输出应为 `PC会〔2026〕7号`（无空格）；现有示例 `7 号` 的空格是排版习惯，机读字段不留空格 |
| 4 | 代字拼写 | ⚠️ 统一：现存两种写法 `PC会`（C 报告借鉴点 1）与 `PC-{类型字}`/`PC-MIN`（协议底稿、演练脚本）并存，建议正式裁决为一种并写入模板常量 |
| 5 | 代字含拉丁字母＋连字符 | 📌 **声明偏离**：现实机关代字均为纯汉字（如"国办发""黔府办发"），`PC-MIN` 属系统自定义记号体系。处理：文档渲染层提供映射（`PC-MIN`→显示为 `PC纪` 或纯汉字代字），或在模板显式声明"电子公文自定义代字"。GB/T 15835 将"公文编号"列为编号场合应使用阿拉伯数字/编号形式的场景，自定义代字本身不违规，但需显式声明 |
| 6 | 联合行文取主办机关文号 | ✅ 已合规（协议底稿裁决与条例第九条第五项一致） |
| 7 | 纪要型文档的文号位置 | 📌 **重要**：GB/T 9704 第 10.3 条纪要专用格式**无发文字号要素**——MIN 型文档若走专用格式，PC 文号只存在于元数据层，不得排入版头（详见 C-补-P05） |
| 8 | 命令型（决议生效令）若有 | 令号单独编排于发文机关标志下空二行居中（10.2），不占普通文号序列 |

## 七、⚠️ 证据污染警示（本轮新发现，供各线复用）

信阳编办全文页所附《党政机关公文格式及排版解读》是新旧标准混排材料，其中大量排版数值出自**已废止的 GB/T 9704—1999**，与现行 2012 国标冲突：

| 参数 | 该解读附件（1999 旧值） | 现行 GB/T 9704—2012 |
|---|---|---|
| 发文机关标志上边缘距版心上边缘 | 25 mm（上报公文 80 mm） | **35 mm**（无 80 mm 规则） |
| 成文日期书写 | 用汉字、"零"写为"○"、右空四字 | **阿拉伯数字**标全年月日、月日不编虚位 |
| 密级位置 | 版心**右上角**第一行 | 版心**左上角**第二行 |
| 分区名称 | 眉首／主体／版记 | **版头**／主体／版记 |
| 抄送机关间分隔 | 用逗号 | 回行与冒号后首字对齐、末尾句号（未规定逗号） |
| 其他 | 含"主题词"、印章下套/中套、距正文 2～4mm 等 1999 特有内容 | 主题词已删除；印章规则见 7.3.5 |

→ 各线引用公文格式细节时，凡出现上述旧值的网页一律不得作为证据；以矿大全文＋官方平台为准（这正是 W1 升级验证的价值所在）。

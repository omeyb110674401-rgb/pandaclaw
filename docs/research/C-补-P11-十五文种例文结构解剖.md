## 二、逐文种结构解剖

标注约定：`[块]→[块]` 表示正文功能块序列；〔体例置信〕＝该类文档法定/高度定型体例且样本为中央层面标准文本；〔归纳〕＝结构据样本与文种通例归纳、引文未逐字核对。功能块四分法沿用方案方向 C：**缘由块 / 事项块 / 要求块 / 结语块**。

### 2.1 决议

**样本 01｜百年奋斗决议（长篇主题决议）**
- 块序：`[标题下通过信息：会议名称+通过日期] → [历史分期回顾块（新民主主义革命/社会主义革命和建设/改革开放/新时代四大时期，逐期叙事）] → ["十个坚持"经验分条块] → [面向未来的部署要求块] → [结语号召块："党中央号召，全党全军全国各族人民要更加紧密地团结在……"〔体例置信〕]`
- 特征观察：
  - **无主送机关、无发文机关署名落款**——决议以"会议"名义成立并公布，标题下的通过信息即其生效标识；
  - 条款组织用分期大块＋条目句式小标题，原则性表述密度极高，几乎不含执行时限、责任单位等操作要素——印证详尽版 1.1「决议概括、原则性条文多，贯彻时需另行制定实施办法」；
  - 全文无"特此决议"式结语套语，以号召段收束。

**样本 02｜人代会政府工作报告决议（短篇批准型决议）**
- 块序：`[审议概况导语："会议听取和审议了国务院总理×××所作的政府工作报告"] → [评价表态块："会议充分肯定…同意报告提出的…总体要求、政策取向和工作部署"] → [批准决定句："决定批准这个报告"] → [结语号召块："会议号召，全国各族人民……而努力奋斗"]`〔体例置信〕
- 特征观察：
  - 三段式极简骨架，是**决议家族中最稳定的变体**：历年人大各报告决议（计划、预算、常委会工作报告等）全部同构，仅替换审议对象与号召关键词；
  - 表态动词链固定：听取和审议→充分肯定/同意→决定批准→号召。

**骨架谱系小结**：决议＝通过信息＋（导语）＋事项主体＋号召收束。两极变体：**长篇主题型**（分期叙事＋经验分条）与**短篇批准型**（审议概况＋表态批准＋号召）。共性硬特征：无主送、无落款机关、以会议名义行文。

### 2.2 决定

**样本 03｜三中全会决定（长篇部署型）**
- 块序：`[标题下通过信息] → [缘由与总目标块：改革的意义、指导思想、"七个聚焦"、到 2035 年总目标] → [分领域部署块：13 个部分、60 条，每条以独立主题句领起] → [结尾落实要求块：加强党的领导、抓好贯彻落实]`
- 特征观察：无主送无落款（与决议同）；事项块占全文九成以上；条目内部大量使用"必须""健全""完善""推进"等指令性动词开头的动宾结构。

**样本 04｜罚款事项决定（短篇事项型）**
- 块序：`[缘由块：为进一步推进"放管服"改革、优化营商环境，国务院组织清理行政处罚事项] → [决定事项块："国务院决定：一、取消…罚款事项…二、调整…"（附清理明细表附件）] → [施行条款块："本决定自公布之日起施行"] → [落款：国务院＋成文日期]`〔体例置信〕
- 特征观察：与决议相反，**决定有落款机关与日期**、可直接成为下级行动准则；变更/撤销类决定的"施行条款"是标配。

**骨架谱系小结**：决定三变体——①部署型长文（总目标＋分领域条目＋落实要求）；②事项型短文（缘由＋决定分条＋施行条款）；③奖惩型（事迹叙述＋授予/处理决定＋希望要求，本批语料未取到公开奖惩型样本，留待补充）。W6 升级：决议 vs 决定的差异现在有真实文本双证——**程序标识（标题下通过信息 vs 落款签发）、效力写法（原则宣示 vs 可直接执行的条款化规定）、收束方式（号召 vs 施行条款）三个维度均可在样本中直接比对**。

### 2.3 命令（令）

**样本 05｜国务院令第 783 号（法规公布令）**
- 块序：`["《公平竞争审查条例》已经 2024 年 5 月 11 日国务院第 32 次常务会议通过，现予公布，自 2024 年 8 月 1 日起施行。"单段成文] → [署名：总理姓名] → [成文日期]`〔体例置信〕
- 特征观察：正文一句话完成「审议经过＋现予公布＋施行日期」三要素；使用专用命令格式（GB/T 9704 第 10.2 条），令号独立编号不占普通发文字号序列。

**样本 06｜省政府令（规章公布令）**
- 块序：与样本 05 同构（省级层面复制中央体例）：`[规章名称＋"已经省人民政府第×次常务会议通过，现予公布，自××起施行"] → [省长署名＋日期]`〔归纳〕
- 特征观察：山西政府门户设「省政府令」专库按令号归档，印证令号单独成序。

**骨架谱系小结**：命令四变体——公布令（上述体例）、任免令（任命名单＋署名）、嘉奖令（事迹＋授予决定＋号召三段，篇幅最长）、动员/强制令。共同硬特征：权限法定、一段式或三段式、签名章/署名生效。

### 2.4 公报

**样本 07｜三中全会公报（会议公报）**
- 块序：`[会议概况导语：时间地点、出席/列席人员范围、主持人] → [议程履行块："全会听取和讨论了×××受中央政治局委托作的工作报告，审议通过了《中共中央关于…的决定》"] → [分主题摘要块：经济体制改革、政治、文化、民生、生态、国家安全等逐题概述] → [人事事项块：递补委员/处分确认] → [结尾号召块]`〔体例置信〕
- 特征观察：公报是**会议内容的对外授权摘要**，本身承载表决结果与人事变动，故比决议多出「议程履行」与「人事事项」两个专属块。

**样本 08｜2024 年统计公报（数据公报）**
- 块序：`[年度定性导语：国民经济总体运行情况一句话定性] → [分章数据块：综合→农业→工业建筑→服务业→固定资产投资→对外经济→财政金融→居民收入消费→教育科技→卫生健康→资源环境→人口就业，逐章数字密集铺陈] → [注释说明块：指标解释、数据口径、修订说明] → [落款：国家统计局＋日期]`〔归纳〕
- 特征观察：无主送、面向公众；正文几乎全部为「指标名＋绝对值＋同比增速」三元组复沓句式。

**骨架谱系小结**：公报三变体——会议公报（概况＋议程＋分题＋人事＋号召）、统计公报（导语＋分章数据＋注释）、外交公报（共识分条＋双方签署）。共性：无主送机关，公开层级最高。

### 2.5 公告

**样本 09｜人大常委会代表资格公告**
- 块序：`[事实陈述块：某省人大常委会补选/罢免情形] → [程序认定块：常务委员会第×次会议根据代表资格审查委员会提出的报告，确认其代表资格有效/终止] → [列举块：逐人逐项列明] → [公告收束："现予公告"/"特此公告"] → [落款：全国人大常委会＋日期]`〔体例置信〕
- 特征观察：公告编号自成体系（〔届〕第×号）；主送对象缺省＝国内外公众。

**样本 10｜商务部反倾销期终复审裁定公告**
- 块序：`[法律依据与立案经过块："根据《中华人民共和国反倾销条例》…进行期终复审调查"] → [裁定结论块：继续征收反倾销税及税率表] → [执行条款块：实施期限自×年×月×日起 5 年] → [落款：商务部＋公告号＋日期]`〔归纳〕
- 特征观察：部委公告带「年度＋流水号」（2024 年第 48 号）编号制；执行条款即结语，不强求"特此公告"。

**骨架谱系小结**：公告＝依据/事实＋决定/裁定＋执行条款＋落款。硬特征：无主送、面向国内外、发布主体层级高（人大常委会、部委及以上）——与详尽版 1.5 的滥用警示（商场开奖"公告"）互证。

### 2.6 通告

**样本 11｜南昌交警交通管理通告**
- 块序：`[缘由与依据块："为保障…道路交通安全畅通，根据《道路交通安全法》…规定，决定对…实施交通管理措施。现将有关事项通告如下："] → [措施分条块：限行时段/区域/车型逐条] → [责任条款块：违反者依法处罚] → [施行条款块："本通告自××起施行"] `〔归纳〕
- 特征观察：面向特定区域社会公众张贴发布；「依据＋决定＋通告如下」承转链是通告的标准开端。

**样本 12｜电子烟通告（两部委联合）**
- 块序：`[背景缘由块：未成年人接触电子烟风险] → [倡导禁止分条块：各类市场主体不得向未成年人销售电子烟] → [呼吁监督块：请社会各界予以监督] → [落款：双机关＋通告号＋日期]`〔归纳〕
- 特征观察：周知提醒型通告可无施行条款，以呼吁性内容收束；联合发布时通告号仍为单一序列（主办机关编号）。

**骨架谱系小结**：通告两变体——管理措施型（含罚则与施行日）、周知提醒型（倡导＋监督呼吁）。与公告的分界在**对象半径**（一定范围公众 vs 国内外）与**事项强度**（应当遵守 vs 重要/法定事项宣布），样本 11/12 与样本 09/10 的对比直观呈现。

### 2.7 意见

**样本 13｜国办发〔2024〕44 号服务贸易意见（下行指导性意见）**
- 块序：`[主送机关：各省、自治区、直辖市人民政府，国务院各部委、各直属机构] → [缘由与指导思想块] → [任务分条块：分领域提出政策措施] → [保障措施块：组织落实、部门分工] → [落款：国务院办公厅＋日期]`〔体例置信〕
- 特征观察：下行意见的措施颗粒度介于决定（刚性）与通知（操作性）之间；常带"经国务院同意"授权标注（呼应条例第十六条第二款）。

**样本 14｜美丽中国建设意见（党政联合长文意见）**
- 块序：`[主送机关：各省区市党委和人民政府、中央和国家机关各部委…] → [总体要求块：指导思想＋工作原则＋主要目标（2027/2035 分节点）] → [七大体系任务块] → [加强党的领导结尾块]`〔归纳〕
- 特征观察：党政联合行文的意见主送至党委系统；「主要目标」给出量化节点是其区别于一般指导文件的要素。

**骨架谱系小结**：意见三向变体——下行指导（总体要求＋任务＋保障）、上行建议（缘由＋建议＋"以上意见如无不妥，请批转各地贯彻执行"结语）、平行参考。本批语料覆盖下行两例；上行结语套语属文种通例，维持 C 级口径待核（P1-3 语料表继续标注）。

### 2.8 通知

**样本 15｜节假日安排通知（事项告知型）**
- 块序：`[主送机关] → [缘由一句："经国务院批准，现将…具体安排通知如下："] → [事项列表块：元旦/春节/清明/劳动/端午/中秋/国庆六个节日安排逐条] → [落款：国务院办公厅＋日期]`〔体例置信〕
- 特征观察：最短的通知样本之一，**无执行要求块也无"特此通知"结语**——证明结语套语是可选件而非必选件。

**样本 16｜政府网站发展指引通知（印发型）**
- 块序：`[主送机关] → [印发语句一块："《政府网站发展指引》已经国务院同意，现印发给你们，请认真贯彻执行。"] → [附件：指引全文] → [落款]`〔体例置信〕
- 特征观察：印发型通知正文仅一句话，「已经×同意＋现印发给你们＋请认真贯彻执行」三短语固定搭配，是转发/印发族的模板句。

**骨架谱系小结**：通知四变体——印发转发型（一语正文＋附件）、事项布置型（缘由＋事项＋执行要求＋可选"特此通知"）、会议告知型（时间地点人员议题材料要求）、任免型。通知是十五文种中**变体最多、结语套语可选度最高**的文种。

### 2.9 通报

**样本 17｜督查问责典型案例通报（批评性）**
- 块序：`[缘由块：近期对××开展专项督查，发现…问题] → [案例分则块：案例一/二/三逐案叙述（地点＋行为＋问责结果）] → [要求块：各地区各部门举一反三、引以为戒] → [落款]`〔归纳〕
- 特征观察：批评性通报的案例分则采用「地点＋违规事实＋处理决定」三元复沓结构，处理决定部分用词最重（免职、党纪政务处分）。

**样本 18｜第九次大督查典型经验做法表扬通报（表彰性）**
- 块序：`[缘由块：为进一步激励担当作为、总结推广经验，经国务院同意] → [表扬清单块：按省份罗列典型经验做法名称] → [希望要求块：受到表扬的地方再接再厉，各地要学习借鉴] → [落款]`〔归纳〕
- 特征观察：表彰性通报的希望块动词强度明显低于批评性的要求块（"希望""鼓励"vs "严禁""坚决纠正"）。

**骨架谱系小结**：通报三变体——表彰（缘由＋名单＋希望）、批评（缘由＋案例＋处理＋要求）、情况传达（情况＋分析＋要求）。事后行文属性使全部变体的缘由块都以"近期/今年以来"回溯开头。

### 2.10 报告

**样本 19｜审计工作报告（向人大常委会的专项报告）**
- 块序：`[称谓与委托声明："全国人民代表大会常务委员会：受国务院委托，我向全国人大常委会报告××审计情况，请予审议"] → [总体评价段] → [分块审计情况与问题清单：中央财政管理/部门预算执行/重大项目/民生资金/国有资产管理，问题逐条列示] → [审计建议块] → [落款：审计署＋审计长＋日期]`〔体例置信〕
- 特征观察：报告的"请予审议"是**请求审议而非请求批准**——不需要也不等待答复，印证详尽版 1.10「报告无需批复」；问题清单条目化程度高，每条含「金额＋主体＋性质」。

**样本 20｜就业工作报告（工作情况报告）**
- 块序：`[委托声明同上] → [工作回顾块：成绩与进展] → [存在问题块] → [下一步工作考虑块] → [落款]`〔归纳〕
- 特征观察：「成绩—问题—打算」三段论是工作报告的经典内部结构；与专项审计报告相比，问题块的自陈比例更高。

**骨架谱系小结**：报告三变体——工作报告（回顾＋问题＋打算）、情况报告（一事一报＋建议）、答复报告（针对上级询问定向回复）。硬特征：主送唯一上级机关、结语可用"特此报告/请予审议"，**禁夹请示事项**（条例第十五条第四项）。

### 2.11 请示

**样本 21｜古田县府办修缮经费请示**
- 块序：`[主送机关：县政府（或指定审批部门）] → [缘由块：办公用房设施老化、存在安全隐患，需修缮改造] → [测算与请求块：列出预算构成与申请金额] → [结语套语："妥否，请批示"/"当否，请批示"族]`〔归纳——引文未逐字核对〕
- 特征观察：县级实务中政府办公室作为内设机构向上行文的形态真实存在（呼应条例「部门内设机构除办公厅（室）外不得对外正式行文」——办公室恰是被豁免者）。

**样本 22｜补贴资金申请请示**
- 块序：`[政策依据块：援引上级文件规定的补助条件] → [本单位情况与测算块] → [请求事项块：申请拨付金额] → [结语套语族同上]`〔归纳〕
- 特征观察：一文一事纪律的直接体现——两份样本各自只申请一类资金。

**骨架谱系小结**：请示＝依据/缘由＋事项＋固定结语。结语套语族高度收敛（妥否，请批示／当否，请批示／特此请示，恳请批复），是十五文种中**结语套语必选度最高**的文种。格式特设：上行文标签发人、附注联系人电话。

### 2.12 批复

**样本 23｜莆田历史文化名城批复（国函）**
- 块序：`[主送机关：福建省人民政府] → [引述来文首句："你省《关于…的请示》（闽政〔××〕×号）收悉。现批复如下："] → [决定事项："一、同意将莆田市列为国家历史文化名城…"] → [保护管理要求分条] → [落款：国务院＋日期]`〔体例置信〕
- 特征观察：「来文标题＋文号＋收悉＋现批复如下」四件套是批复的法定开场；决定与要求合并在同一编号序列中。

**样本 24｜沂水县用地方案批复**
- 块序：`[主送原请示单位] → [引述来文] → [同意决定＋后续程序要求（备案、公示）] → [落款]`〔归纳〕
- 特征观察：县级批复同样严格保持一一对应（一份请示一份批复）；标题完整复述来文事由。

**骨架谱系小结**：批复＝引述来文＋决定＋要求。硬特征：主送＝原请示机关、首句必引来文标题与文号、「现批复如下」承转套语。批准性与否定性两种走向中，公开样本以批准性为主。

### 2.13 议案

**样本 25｜企业破产法草案议案（1986）**
- 块序：`[主送：全国人民代表大会常务委员会] → [提请语句一两句："国务院提请审议《中华人民共和国企业破产法（草案）》，请予审议"] → [附件：草案全文] → [落款：国务院总理＋日期]`〔体例置信〕
- 特征观察：议案本体极简——正文一两句话，实质内容由附件承载；这是十五文种中**正文最短的文种**。

**样本 26｜茂南区山阁镇总体规划修改议案**
- 块序：`[主送：区人大常委会] → [缘由与法律依据块：《城乡规划法》规定＋规划期限调整必要性] → [提请审议语句] → [附件：规划修改方案] → [落款：区人民政府]`〔归纳〕
- 特征观察：地方层面的议案同样走「依据＋提请审议＋附件」极简路线；使用主体单一（政府→同级人大/常委会）得到地方实例印证。

**骨架谱系小结**：议案＝法定通道文种，正文模板化程度最高（提请＋请予审议），信息量全在附件。与函的请求批准功能分界：**受理方是否为同级权力机关**。

### 2.14 函

**样本 27｜济南起步区实施方案复函（国办函）**
- 块序：`[主送：山东省人民政府] → [引述来文＋承转："你省《关于…的请示》（鲁政呈〔××〕×号）收悉。经国务院同意，现函复如下："] → [答复事项分条："一、原则同意《…实施方案》…"] → [落实要求] → [落款：国务院办公厅＋日期]`〔体例置信〕
- 特征观察：国办答复地方政府用「函」而非批复——因二者不相隶属（授权行文场景）；「经国务院同意」授权标注出现在承转句中（呼应条例十六条第二款、H 方向灰区线索）。

**样本 28｜安徽两厅学费标准复函（联合平行函）**
- 块序：`[主送：相关单位] → [引述来文] → [核定事项块：分项收费标准（表格化列示）] → [执行要求块：明码标价、收费公示、退费规则] → [落款：双机关联合]`〔归纳〕
- 特征观察：不相隶属部门间的定价答复用函；联合复函落款双机关、共用一个文号（主办机关代字）——P1-2 联合行文代字规则的直接样本。

**骨架谱系小结**：函四变体——商洽函（缘由＋事项＋"望函复为盼"）、问答复函（引述＋"现函复如下"）、请求批准函（缘由＋请求＋"可否，请函复"）、告知函。硬特征：信函格式专用版式（GB/T 9704 第 10.1 条）、结语必留回复接口或径直答复。

### 2.15 纪要

**样本 29｜锡林浩特市政府第 24 次常务会议纪要**
- 块序：`[纪要标志＋期号（"2024 年第 24 次"会议序号式）] → [导语五要素块：时间、地点、主持人、出席/列席人员、议题] → [逐议题议定块：每议题按"听取了××汇报→会议认为→会议决定/议定"展开] → [落实要求块：责任单位与时限嵌入议定条款] `〔归纳——引文未逐字核对〕
- 特征观察：编号采用**会议次序式**而非发文字号式（无代字无六角括号年份），与 GB/T 9704 第 10.3 条「纪要无发文字号要素」一致；公开于政府门户「政府公报·会议纪要」专栏。

**样本 30｜泰兴市政府第 38 次常务会议纪要**
- 块序：同构；按年度期号归档于政府门户网站会议纪要栏目。〔归纳〕
- 特征观察：两份样本均为**市级政府常务会议纪要主动公开**实例，头部要素高度一致，支持纪要分类模板的可参数化设计（详见 C-补-P14）。

**骨架谱系小结**：纪要＝标志＋导语五要素＋逐议题议定块＋落实分工。「会议认为/指出/强调（定性层）→会议决定/同意（议定层）→会议要求（督办层）」三级动词分层是议定事项块的通用语法。硬特征：无主送、无印章、无发文字号、凭红色专用标志生效（10.3 体例，详见 C-补-P05 定性）。

## 三、十五文种骨架变体谱系总表

| 文种 | 基础骨架 | 变体谱系 | 必选件 | 可选件 | 生效标识 |
|---|---|---|---|---|---|
| 决议 | 通过信息＋事项主体＋号召 | 长篇主题型／短篇批准型 | 通过信息、事项主体 | 导语、分期叙事 | 会议名义（无落款） |
| 决定 | 缘由＋决定事项＋施行 | 部署型／事项型／奖惩型 | 决定事项 | 施行条款、附件 | 落款机关＋日期 |
| 命令（令） | 审议经过＋现予公布＋施行 | 公布令／任免令／嘉奖令 | 公布语句、署名 | 事迹叙述 | 署名（签名章）/令号 |
| 公报 | 概况＋议程＋分题＋号召 | 会议公报／统计公报／外交公报 | 概况导语 | 人事事项、注释 | 授权发布 |
| 公告 | 依据/事实＋决定＋执行 | 资格公告／裁定公告 | 事实或依据、决定 | 执行条款 | 落款机关＋公告号 |
| 通告 | 缘由依据＋事项分条＋施行 | 管理措施型／周知提醒型 | 事项分条 | 罚则、监督呼吁 | 落款＋通告号 |
| 意见 | 总体要求＋任务＋保障 | 下行指导／上行建议／平行参考 | 任务主体 | 主要目标量化 | 落款（下行）或批转（上行） |
| 通知 | 主送＋正文＋落款 | 印发转发／布置／会议告知／任免 | 正文核心句 | 执行要求、结语套语 | 落款＋文号 |
| 通报 | 缘由＋主体内容＋要求 | 表彰／批评／情况传达 | 主体内容 | 处理决定 | 落款＋文号 |
| 报告 | 委托声明＋回顾＋打算 | 工作报告／情况报告／答复报告 | 委托声明（向人大） | 问题自陈、建议 | 落款（不需答复） |
| 请示 | 缘由＋事项＋结语套语 | 批准请求型／指示请求型 | 一文一事、结语套语 | 测算明细 | 落款＋文号＋签发人 |
| 批复 | 引述来文＋决定＋要求 | 批准性／否定性 | 引述来文首句 | 保护/备案要求 | 落款＋文号 |
| 议案 | 提请语句＋附件 | 法规草案／规划调整／条约批准 | 提请＋请予审议 | 依据说明 | 落款＋附件承载实体 |

## 四、对 PandaClaw 六类会议输出物骨架模板库的映射

1. **决议型输出物**：默认采用样本 02 的短篇批准型三段式（审议概况→表态批准→号召），复杂议题升级为样本 01 长篇主题型；标题下自动生成「经××会议×年×月×日审议通过」通过信息字段，替代落款。
2. **纪要型输出物**：采用样本 29/30 骨架，导语五要素做成必填元数据；议定事项按三级动词分层渲染（认为→决定/同意→要求），责任单位与时限字段从议定条款结构化抽取（衔接 C-补-P14 督办模块）。
3. **通知型输出物**（周知/布置）：默认事项布置型；纯转发场景降级为一语正文＋附件。
4. **函询/商洽型输出物**：跨团队协商用商洽函骨架，结语强制保留回复接口套语；答复场景用问答复函骨架并自动引用来文标题文号。
5. **上报/提请型输出物**：向上级系统的请示用「缘由＋事项＋妥否请批示」骨架并强制一文一事校验；向同级代议机构提请的议案用极简正文＋附件模式。
6. **公开发布型输出物**（公告/公报）：无主送字段；公告号/公报号独立编号器；统计公报的分章数据块可映射为 PandaClaw 会议数据的结构化报表视图。

**跨文种通用发现（供渲染层）**：
- 无主送文种集合＝{决议, 决定(全会), 命令, 公报, 公告, 通告}——这些文种的模板不应渲染主送机关字段；
- 「标题下通过信息」vs「末尾落款」二选一生效标识规律：会议名义文种（决议、全会公报）前置，机关名义文种后置；
- 结语套语非必选件（节假日通知无任何结语套语仍合法），但请示/批复/函三类交互型文种结语近乎必选——审核器应对交互型文种开启结语强校验。

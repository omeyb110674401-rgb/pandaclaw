# B-补-P14 · 界别协商的组织流程与界别召集人制度

> 任务卡来源：《B-政协制度-后续调研方案.md》P1-4。执行方式：《遵义市委员会界别协商工作规则》（2024-12-24 六届十五次常委会通过）二十四条全文＋《天津市河北区委员会界别召集人工作规则（试行）》全文两份制度文本互证。
> 关键附带发现：遵义规则第一条制定依据中明文援引**《中国人民政治协商会议全国委员会界别协商工作规则》与《政协贵州省委员会界别协商工作规则》**——全国政协层面确有专门的界别协商工作规则（2025 综述亦载当年实开界别协商会 16 次），但全文未公开检索到；本卡以两份地方全文作 B 级还原。

## 一、事实结论

### 问题 1：界别召集人如何产生、职责是什么

**产生（两份地方文本互证，B 级）**：

| 要素 | 遵义市（2024） | 天津河北区（2017 试行） |
|---|---|---|
| 名额 | 每界别 1～3 名 | 每界别若干名 |
| 来源 | 本界别委员；**牵头单位班子成员任政协委员者应为第一召集人** | 本界别委员；原则上由党派、团体负责同志和界别牵头单位负责同志担任 |
| 牵头单位 | 换届时推荐本界别委员的单位（多个＝共同牵头单位） | 界别牵头单位 |
| 审定程序 | 委员联络服务中心拟定→**主席会议审定** | 政协委员联络室提出→党组、主席会议审议→**常委会议审议确定** |
| 任期 | （随规则未单列） | 与本届政协任期相同 |

**职责（天津河北区规则原文归纳）**：

- 全体会议期间：①组织本界别委员参加会议讨论或**界别联组讨论**，组织撰写提案、反映社情民意；②**列席常委会议并汇报本界别或联组讨论情况**；③**以界别名义参加大会发言的组织工作**；④承办大会秘书处安排事项。
- 闭会期间：①拟定本界别年度工作计划和方案，报主席会议审定后实施，向主席会议、常委会议报告界别工作；②组织协调界别学习、**界别协商、界别视察、界别调研**、理论研究与社会公益活动；③联系本界别委员群众，组织撰写**界别提案**和社情民意信息；④与区政协相关部门和对口专门委员会联络；⑤与其他界别和专门委员会**联合履职**的组织协调；⑥协助委员考核管理；⑦就改进界别工作提出建议。
- 履职管理：《政协委员履职手册》记载＋**向区政协常委会述职**＋每届至少两次专题培训。

### 问题 2：界别活动的发起方式

遵义规则的完整发起链（B 级全文）：

1. **统筹指导分工**：「界别协商工作由市政协委员联络服务中心负责统筹，各专门委员会具体指导，**召集人为主、牵头单位为辅具体负责组织实施**，市政协办公室给予保障」。
2. **年度计划立项**：每年年终和全会闭幕后，各专委会充分征求所联系界别牵头单位和召集人意见→提出该界别年内拟开展的界别协商活动安排计划（含界别、议题、时间、拟邀请市直单位）→报委员联络服务中心汇总形成**年度各界别协商工作计划**→**主席会议审定**后实施。
3. **逐场方案备案**：牵头单位和召集人在专委会指导下按年度计划制定具体工作方案（明确时间、地点、参加人员、成果转化方式）→**向相关专门委员会备案后实施**；专委会督促指导并派员参加。
4. **频次约束**：闭会期间每个界别每年组织 **1～2 次**界别协商活动；原则上单独开展，「人数较少且领域相近的界别可以联合开展」。
5. **活动形态**：可组织小范围调研、走访相关单位和企业、听取专家学者和界别群众意见、小规模视察考察座谈；另可在数字平台开设界别委员专栏开展线上研讨（「遵i协商」）。

即：现实模式不是召集人随意发起，而是**「年度计划立项＋逐场备案」双闸门**，召集人是执行主体而非立项主体。

### 问题 3：界别协商成果的出口

遵义规则第十六、二十二条（B 级全文）：委员意见建议可采取**简报、专报**等形式反映，也可视情况转化为：
- **界别提案**
- **界别大会发言**
- **界别社情民意信息**

闭会期间的活动意见还可以报告等形式报送市委、市政府有关领导和部门；并且**「意见的采纳应及时向本界别全体委员反馈」**——成果去向有明确的回告义务。年度执行情况进入各专委会工作报告（第二十三条）。

### 问题 4：跨界别联组的触发条件与组织

- 全会期间联组是**常规安排而非触发制**：遵义规则第十二条——全体会议期间一般安排 2～3 次界别小组会议＋**至少安排 1 次界别联组会议**，按界别分组，协商讨论议题根据全体会议内容确定。
- 组织规格分层：界别小组会议由本组委员推举的委员小组组长主持（组长产生前由界别召集人代持），**主席会议成员到所联系的界别出席**；**界别联组会议由主席会议成员主持，邀请市委、市政府领导同志及市直有关部门出席**——联组比小组高一级：主持人升级为主席会议成员、必邀党政部门。
- 会议流程四段（第十五条）：主持人简要介绍情况 → 委员发言 → 列席单位负责同志互动交流 → 出席会议的市领导同志讲话。
- 闭会期间的联合形态：人数较少且领域相近的界别**可以联合开展**协商活动（低门槛合并）；天津规则另赋予召集人「与其他界别和专门委员会联合履职的组织协调」职责。

## 四、对协议条款/模板的影响判断

1. **§6 身份库分组拓扑（验收标准达成）**：协议的 cppcc 身份分组可直接采用现实命名——「界别＝专业身份组」，每组设「界别召集人」（agent 场景可映射为该身份组的默认发言人/组织者）；「牵头单位＝提名来源方」。分组讨论编组依据已有 A 级出处（《常务委员会工作规则》十五条「可按界别编组，也可混合编组」，见 P05 附录），本卡补充了界别内更细一层：**小组长由组内推举、召集人为当然主持候选**。
2. **联组机制的现实命名依据**：协议「跨域议题临时组队」可正式命名为「联组」并注明现实原型——联组会的现实特征是①常规化（每次全会至少一次）而非纯触发式；②主持人升级（主席会议成员）；③必邀被议对象（党政部门）。协议设计跨组议题回路时可借用此三级特征：跨组合并→主持人升格→强制 npc 部门到场。
3. **任务路由注释**：召集人职责清单中的「与对口专门委员会联络」「组织撰写界别提案」支持协议的身份组→产出物路由：界别组成员的意见书可打上界别标签，走「界别提案/界别发言/社情民意」三通道转化，与 M3 提案通道并行不悖。
4. **R0/R1 参数**：闭会期间每界别每年 1~2 次、全会期间 2~3 次小组会＋≥1 次联组会的频次结构，可为多议题排程提供现实频率参照；「采纳应及时向本界别全体委员反馈」是 M9 处置清单反馈义务的又一出处（反馈对象从提案者扩展到所在群体）。

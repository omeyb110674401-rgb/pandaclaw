# B-补-P11 · 专题议政性常委会会议全流程

> 任务卡来源：《B-政协制度-后续调研方案.md》P1-1。执行方式：《新时期人民政协工作指南》形式定义卡（贵港政协转载）＋门头沟区政协《议政性常务委员会会议实施细则》（2017 通过 / 2022 修订）十条全文＋十四届两次常委会会议新华社通稿＋《常务委员会工作规则》2018 版相关条款交叉核验。
> 核心结论先行：**全国政协层面无公开的《专题议政性常委会议工作规则》**，其流程由《常务委员会工作规则》统摄＋年度协商计划安排＋历次会议惯例构成；流程骨架可由「地方实施细则全文＋全国实例通稿」以 B 级还原。

## 一、事实结论

### 问题 0：形式定位（是什么）

- 《新时期人民政协工作指南》口径（贵港市政协官网转载）：专题议政性常委会议由政协组织提供平台，以常务委员会会议为主要形式，组织党派团体、政协委员就经济社会发展中某一重要问题，**在深入调研基础上**，与党政领导、有关职能部门负责人直接进行协商议政。特点四条：抓前瞻性、战略性问题；党政高层领导出席；形成对话和互动机制；提出比较成熟的意见建议。
- 《常务委员会工作规则》2018 修订版第八条（B-补-P03 已 A 级核验）：常委会会议一般每季度举行一次；常务委员会**每年至少举行两次专题议政性会议**。
- 实例印证：十四届常委会第十七次会议（2026-06-23～24）议题「坚持高质量发展，推动经济持续健康发展和社会全面进步」；第十八次会议（2026-08-25 开幕）议题「加大保障和改善民生力度，扎实推进全体人民共同富裕」——均为单一主题、围绕国家战略议题。

### 问题 1：选题如何进入常委会

三源拼合的选题链（B 级）：

1. **源头＝年度协商计划**：门头沟细则第三条——议政性常委会议题来源于党委办印发的政协**年度协商工作计划**，「每次围绕一个专题召开」，由政协研究室将议题列入协商工作安排，**经常委会会议审议通过后组织实施**。全国层面的对应机制见 B-补-P04：年度协商计划由中央办公厅、国务院办公厅与政协办公厅会商→政协主席会议审议→报中共中央审定（2015 实施意见第五条）。
2. **频次约束**：全国政协每年至少 2 次（常委会工作规则第八条）；门头沟区每年 1～2 次（并括注「市政协是至少两次」）——层级越低频次弹性越大。
3. **议题属性**：前瞻性、战略性重大问题（指南口径）；实例均为五年规划、高质量发展、共同富裕一类宏观主题——与双周座谈「小切口」形成鲜明对照。

### 问题 2：会前调研与分组讨论安排

- **会前流程（门头沟细则第四条，B 级全文）**：由**议题主牵部门**负责制订前期调研考察活动组织实施方案 → 召开**情况通报会或专题报告会** → 组织常务委员、课题组成员和其他有关人员深入开展调查研究 → 形成**调研报告和系统化的意见建议** → 向常务委员会汇报。即：调研不是松散前置项，而是有实施方案、有通报会、有成文产出的必经程序。
- **会中组织**：《常务委员会工作规则》2018 版第十五条（B-补-P05 附录已摘）：采取全体会议和分组会议相结合的方式，「根据会议议题，**可按界别编组，也可混合编组**」。全国实例通稿证实分组审议/讨论贯穿会期（如十四届四次全会分组审议报道同构）。
- **通知时限**：门头沟细则第五条——议程日程由驻会主席会议确定，一般由分管副主席主持，会议通知**会前三天**送达（注：全国层面常委会例会是半个月通知，B-补-P03；三天是区级议政性常委会的更紧时限，因属专项小规模会议）。
- **出席门槛**：门头沟细则第六条重申常委会全体组成人员 2/3 以上出席方能举行，请假须提前一天向办公室报告。

### 问题 3：部门负责人到会作报告的环节位置

- 全国实例（新华社通稿，A 级一手报道）：十四届常委会第十八次会议**开幕会**上，中共中央政治局委员、国务院副总理何立峰**应邀出席会议并作报告**（内容为落实「十五五」规划纲要的民生重点任务），全国政协副主席主持开幕会；开幕会同场听取主席会议关于上半年工作情况的报告、副主席兼秘书长就有关议题作报告和说明。
- 地方细则第七条：举行时邀请区委、区政府主管领导及有关部门负责人到会，**听取意见和建议，并对委员提出的意见建议作出积极回应**，也可邀政协委员或专家学者列席。
- 结论：**部门负责人作报告的位置＝开幕会第一阶段**（政协领导主持→部门领导作情况报告→随后进入分组讨论/大会发言），且负有「回应委员意见」义务。这与双周座谈「先请 1 位部门负责人简要介绍情况」（工作规则第十一条）结构同源、规格放大。

### 问题 4：会议产出（成果文件形式与报送对象）

- 《新时期人民政协工作指南》口径：会议成果以**政协建议案、党组报告、主席会议报告、大会发言专报、政协信息**等形式报送党委和政府及有关部门。
- 地方细则第八条的成文责任链：会后由**议题主牵部门**起草党组关于会议协商意见的报告 → 政协研究室修改完善 → 政协办公室按协商成果报送文件要求报送。
- 对照《常务委员会工作规则》：建议案由秘书长签发（B 报告 §1.1-5 已核）；常委会会议可表决通过人事及决议类事项（十七次会议闭幕会「经表决」通过增补、请辞、免职等决定——新华社通稿原文）。
- 闭幕会形态：主席主持并讲话（王沪宁于十七次会议闭幕会讲话全文见新华社通稿）；闭幕会后常设学习讲座环节。

### 问题 5：一次典型会议的完整时间线（综合还原，B 级）

| 步骤 | 内容 | 依据 |
|---|---|---|
| ① 计划立项 | 议题列入年度协商计划（党政协商→主席会议审议→报党委/中共中央审定） | 门头沟细则三；2015 实施意见 |
| ② 会前调研（约数月） | 主牵部门制定调研实施方案→情况通报会→实地调研考察→形成调研报告 | 门头沟细则四 |
| ③ 会议通知 | 例会提前半个月；专项议政性常委会（地方实践）提前三天 | 工作规则第九条；门头沟细则五 |
| ④ 开幕会 | 政协副主席/主席主持；国务院分管副总理或部门负责人应邀到会作报告；听取主席会议工作报告等 | 十八次会议通稿 |
| ⑤ 分组讨论＋大会发言 | 按界别或混合编组讨论；大会发言交流调研成果与建议 | 工作规则十五条；指南「大会发言专报」产出反推 |
| ⑥ 闭幕会 | 主席主持讲话归纳共识；表决通过有关决定；视情安排学习讲座 | 十七次会议通稿 |
| ⑦ 成果报送 | 协商意见经主牵部门起草→研究室完善→办公室报送；重要成果以建议案（秘书长签发）、党组报告、信息专报等形式送党委政府 | 门头沟细则八；指南 |

## 四、对协议条款/模板的影响判断

1. **PLA/STR 类型 ⭐审议阶段骨架**（验收标准达成）：大流程「⭐审议」阶段可加注现实锚点——「现实对应物为专题议政性常委会：开幕听部门报告→分组/界别编组讨论→闭幕表决/形成协商意见→党组报告+建议案双轨报送」。七步时间线可直接作为 PLA 类型阶段流注释。
2. **M5 对照（大小回路衔接）**：议政性常委会与双周座谈共享同一套「部门报告→委员发言→互动回应→归纳报送」基因，仅规模与时限不同——支持协议 simple/complex/full 三档共用回路原语、仅参数不同的设计。
3. **R3/主持人角色**：现实「议题主牵部门起草→研究室完善→办公室报送」的三段成文链提示：协议中定稿文书应由「议题发起人起草、主持人合议、秘书职能归档报送」分工，可在 R3 条文注释中补充此现实原型。
4. **模板影响**：STR 类型的「情况报告」文档可对标开幕会部门报告（由 npc 承办方生成）；「协商意见报告」对标党组报告（cppcc 院最终产出），两者已是协议既有产物，无需新增文种。

## 一、国务院常务会议（A 级条文＋个案印证）

### 1. 法定架构（组织法第七、八、九条原文要点）

| 要素 | 条文内容 |
|---|---|
| 组成 | **总理、副总理、国务委员、秘书长**（全体会议则为国务院全体成员） |
| 召集主持 | **总理召集和主持**全体会议和常务会议 |
| 强制合议 | 「国务院工作中的重大问题，**必须经国务院常务会议或者国务院全体会议讨论决定**」 |
| 常务会议任务 | 讨论**法律草案**、审议**行政法规草案**；讨论、决定、通报重要事项 |
| 公开义务 | 「讨论决定的事项，除依法需要保密的外，应当及时公布」 |
| 生效签署 | 行政法规、决定、命令、议案、任免**由总理签署**（第九条） |

### 2. 运行参数（《国务院工作规则》2023 年修订版）

- 频次：**一般每月召开 2–3 次**，如有需要可随时召开（2018 版原为每周一次——频次下调但机动性增强）；
- 列席：根据会议议题安排有关部门、单位负责人列席；
- 五项任务清单：①讨论需提请**党中央**审议、决定的重要事项；②讨论需提请国务院全体会议审议的事项；③讨论法律草案、审议行政法规草案；④讨论通过以国务院名义印发的重要规范性文件；⑤其他重要事项。

### 3. 决定方式：首长负责制下的合议（综合 A 级条文＋个案）

- 结构特征＝**合议讨论＋总理拍板**：会议必须集体讨论（重大问题强制上会），但最终决定权在总理负责制框架内，产出以总理签署为准——不是表决制，也非名义协商一致；
- 个案印证（见 D-补-P17）：2004 年一号文件送审稿经国常会审议后「对……9 个部分表示**原则同意**」；2010 年国常会审议「提出了修改意见」由起草组连夜再改——**「原则同意」「提出修改意见」是国常会审议输出的两种典型形态**，均非票决记录；
- 汇报人实态：会议由总理主持、**事项承办部门/起草组负责人汇报**（2004 年案：温家宝「听取文件起草组汇报」；历年通稿固定句式「会议听取了×××的汇报」）。

## 二、中央全会审议《建议》的程序细节（B+，二十届四中全会全链条实录）

「十五五」规划建议从起草到表决的完整时间线（新华社诞生记逐日披露）：

| 时点 | 动作 |
|---|---|
| 2025-01 | 政治局常委会、政治局先后开会**决定成立文件起草组，总书记任组长** |
| 1 月下旬 | 党中央下发通知：全会议题在**党内一定范围征求意见**＋征求党外人士意见 |
| 2-11 | 起草组第一次全体会议（总书记提要求＋12 方面战略任务＋44 个重大问题清单） |
| 2-下旬 | **6 个调研组赴 12 省区市**，访谈省区市党政主要负责同志，深入 66 个基层单位、访谈干部群众 270 余人 |
| 4-30 / 5-6月 | 总书记主持部分省区市座谈会；委托中央领导同志主持 3 场座谈会（经济界/科技界/基层）；35 项重点课题委托研究 |
| 5-20~6-20 | **网络征求意见活动：有效建言 311.3 万余条**→梳理为 27 个方面 1500 余条；情况报告呈总书记审阅并**提交政治局常委会会议** |
| 8-04 起 | 规划建议稿**党内一定范围组织讨论、征求意见** |
| 8-27 | 中共中央召开**党外人士座谈会**（总书记主持），听取各民主党派中央、全国工商联负责人、无党派人士代表意见 |
| 9 月 | 各地区各部门各方面对征求意见稿提出修改意见 **2112 条**，起草组增写改写精简 **218 处** |
| 9-10月间 | **总书记先后主持 3 次政治局常委会会议、2 次政治局会议审议送审稿** |
| 10-20 上午 | 全会开幕：**总书记就规划建议讨论稿向全会作说明** |
| 10-20 下午起 | 168 名中央委员、147 名候补中央委员及列席人员**分成 10 个小组讨论讨论稿**，提出修改意见 **176 条**→起草组作出 **19 处修改** |
| 10-22 晚 | 政治局常委会会议审议修改稿 |
| 10-23 上午 | 修改稿**再次提交全会分组征求意见**→作出 1 处修改→形成**表决稿** |
| 10-23 下午 | 全会第二次全体会议**表决通过**（「通过！」） |

### 决定形式归纳

1. **说明人**＝最高领导人本人（就讨论稿向全会作说明）；
2. **分组讨论机制**＝按小组分散审议（本届 10 组），意见汇总后由起草组统一消化修改；
3. **两轮循环**＝讨论→修改→常委会再审→再分组征求意见→表决稿（「几上几下」在全会层面同样存在）；
4. **终局形式**＝第二次全体会议口头表决通过（鼓掌欢呼式一致通过场景），而非计票表决记录。

## 三、映射建议

### 对 LEG「合规审查→审议」阶段

| 现实要素 | 建议 |
|---|---|
| 常务会议任务③明列「讨论法律草案、审议行政法规草案」 | LEG 的「⭐审议」闸门有直接法条出处（组织法第八条），条文标注可直接引用 |
| 「原则同意／提出修改意见」两种输出形态 | 审议阶段输出枚举改为三值：`原则通过`（进入签署公布）｜`退回修改`（回到起草，附修改意见清单）｜`暂不讨论`；不做计票表决 |
| 总理召集主持＋部门负责人列席汇报 | 会议角色固定：主持人=机构首长；汇报人=起草方代表；列席者可发言不决策——LEG 会话中 npc 责任方作汇报、主持人总结定案 |
| 重大问题强制上会（第七条）+ 及时公布义务（第八条） | LEG 审议不得跳过（程序红线）；审议结果除涉密外应生成公开纪要 |
| 提请党中央审议事项排在任务① | 党政顺序的条文依据：涉及党的领导事项先报党中央再走政府程序——STR 上位程序的现实注脚 |

### 对 STR「⭐审议/批准」阶段

| 现实要素 | 建议 |
|---|---|
| 起草组组长=最高负责人亲自担任 | STR 起草阶段的主持人规格即最高决策者，审议阶段说明人也由其担任——「起草-说明」同人结构可作为 persona 设计参考 |
| 3 次常委会＋2 次政治局会议递进审议送审稿 | 批准前的多级审议链有具体次数实证（比 D-补-P17 的两级模型更细）；STR 可保留「内圈多轮→外圈终审」抽象，不必写死次数 |
| 全会分组讨论 10 组、176 条意见、19 处修改、二次征求意见 | ⭐批准门内部结构：分组并行审议→意见汇总处置（逐条留痕）→修改→复核→表决稿；意见处置率与修改数写入纪要 |
| 第二次全体会议表决通过 | 表决动作放在全体集合环节完成，分组讨论只产意见不做决议——对应协议中 R4 表决须全员会话而非分组板书 |
| 网络建言 311 万条直达常委会审阅 | 意见征求(⭐)的最高配置样本：公众意见可上浮至终审环节（PLA 十步骤之外的党内版本，供 CON/STR 大规模征意档位参照） |

**证据等级声明**：组织法与《国务院工作规则》条款为官方全文核对（A）；全会程序细节出自新华社长篇纪实（一手通讯社稿，多家央媒转载一致，B+）；国常会「汇报-讨论-原则同意」实态另有 D-补-P17 两案例背书。

## 一、制度文本要点：《吉林省人大常委会立法听证规则》（2023 修改版，A）

| 要素 | 条文规定 |
|---|---|
| 适用情形 | 法规草案涉及①重大经济社会发展问题②热点难点③对权益有较大影响④不同利益群体有明显冲突⑤对必要性或内容有较大争议等 |
| 组织者 | 省人大专门委员会／常委会办事机构或工作机构，可联合举行；主任会议可指定（第五条） |
| **公开与公告** | 应当公开举行；**举行前 20 日**通过新闻媒体发布公告，公布听证事项及陈述人、旁听人报名办法（第六条） |
| 听证人 | 组织听证的专门委员会成员和机构人员；其他委员会成员可列席（第七条） |
| **陈述人遴选** | 由组织者集体遴选；原则＝「**不同观点的各方人数基本相当**」；数量一般**不少于 10 人、最多不超过 20 人**（第八条） |
| 材料送达 | 举行前 **10 日**书面通知陈述人时间地点事项并提供相关材料（第十条） |
| 主持人 | 听证人推选 1–2 人（第十一条）；负责介绍人员、说明事项、宣布程序和纪律（第十二条） |
| 会中流程 | 陈述人围绕听证事项陈述观点理由或提供情况→可在主持下**围绕分歧点辩论**→听证人提问、有关人员回答（第十三、十四条）；法规提请机关及相关部门代表列席并作说明（第十四条） |
| 旁听 | 设旁听席；提前 2 日通知获准公民；旁听人可提交书面意见（第十五条）；允许媒体采访报道（第十六条） |
| 记录 | 指定人员记录并制作听证笔录，须客观真实准确全面；书面陈述意见可直接作为笔录；纸质＋电子存档（第十七、十八条） |
| **成果输出** | 会后组织者向常委会提交**书面听证报告**，作为审议法规的重要参考；内容三部分：基本情况／陈述人主要观点及理由／听证人的意见建议（第十九条） |

## 二、国家级操作实例：2005 年全国人大首次立法听证会（B+ 当事人纪实）

个人所得税工薪所得减除费用标准听证会，2005-09-27 北京：

- **动议层级**：法律委、财经委、法工委三家决定，经**委员长会议同意**；
- **报名规模**：4982 件公众报名申请；
- **遴选三重配额原则**（公告载明）：东中西部地区适当名额＋高低收入行业职业适当名额＋**代表不同观点各方适当名额**；
- **两轮筛选**：书面审查＋电话沟通（考察表达）→40 人候选→最终 **20 人任公众陈述人**，其余转旁听；
- **官方陈述人配置**（共 8 人）：起草部门财政部/税务总局/国务院法制办各 1 人＋全国总工会 1 人＋沪粤皖蒙 4 省（区、市）财税部门各 1 人；
- **发言规则**：预备会告知**每名陈述人发言 8 分钟**、「不讲客套话、开门见山亮明观点」；不得超时；工作人员指导仅限技术层面、不得干预内容；陈述人连夜精简稿子；
- **会期与传播**：整整一天；中国人大网文图直播，媒体现场报道；
- **成果回流**：听证报告作为**常委会二次审议的会议参阅资料印发全体组成人员**；最终立法结果将起征点由 1500 元上调至 1600 元——听证意见实质影响条文数字。

## 三、程序脚本提炼（供 LEG/CON 直接搬用）

```
[0] 触发判定   草案涉重大利益冲突/争议大 → 决定听证（组织者自定或主任会议指定）
[1] T-20日    发布公告：听证事项＋陈述人/旁听人报名办法
[2] 遴选      书面审查＋沟通考察 → 按地域/行业/观点三方配额选定陈述人10–20人
              （观点对冲原则：不同立场人数基本相当）
[3] T-10日    向陈述人送达：时间地点事项＋背景材料
[4] 预备会    告知规则：每人限时（国家级先例=8分钟）、直陈观点、技术性指导不涉内容
[5] 会议      主持人开场介绍→逐人限时陈述→围绕分歧点辩论→听证人提问·部门说明
              （旁听席同步开放，旁听意见以书面形式并入）
[6] 记录      全程笔录（书面意见可直接入录），双介质存档；媒体可报道、网络可直播
[7] 报告      会后出具听证报告（基本情况/主要观点理由/意见建议三段式）
              → 印发审议机关全体成员，作为正式审议参阅件
```

## 四、映射建议

### 对 LEG「专家论证(⭐)」

| 现实要素 | 建议 |
|---|---|
| 陈述人按「不同观点人数基本相当」遴选 | 论证组不能全是支持者：系统在组建论证组时按立场分布强制平衡，避免论证沦为背书 |
| 提前 20 日公告＋10 日送达材料 | 论证前的信息充分性门槛：参会者必须提前拿到完整草案材料，临时召集无效 |
| 听证报告三段式＋印发全体审议成员 | 论证产出固定模板；报告直接进入批准门的参阅附件列表（与 P18 的报批材料清单合并使用） |

### 对 CON R2 交叉质询

- **限时答辩参数**：国家级先例＝单人单轮 8 分钟、全天完成 28 人陈述；省级制度未设具体分钟数但要求「围绕分歧点辩论」。建议 CON R2 采用「首轮陈述限时限次＋分歧点集中辩论」结构，8 分钟可作为 simple 档默认值候选（与 P1-12 双周座谈参数一并交 M5 校准）。
- 与既有产出的关系：`D-补-P04` 已从《规章制定程序条例》侧提炼过行政听证五步脚本；本条补充的是**权力机关立法听证**版本，两者差异点在于陈述人遴选的配额制与报告回流常委会审议这两处，LEG 两级模板应分别引用。

**证据等级声明**：吉林规则为官方全文逐字核对（A）；2005 个税听证细节为当事人纪实（《法制日报》刊发、地方人大官网转载），关键数字（4982/40/20/8 人/8 分钟）单一来源但系当事人叙述，标 B+；如需升 A 可后续比对全国人大常委会公报原文。

# PandaClaw 复审模块化与可替换架构工作文档

> 状态：已批准（grilling 裁定链 Q1–Q27，2026-08-27）
> 范围：本轮回合（A 阶段）落地模块化 + AgentHost 抽象；B′（一键预设终局）记入后续章节，不在此轮回合实现。
> 关联：ADR-0011（复审执行模型韧性）、ADR-0010（复审回告闭环）、本工作文档落档后转 ADR-0012。

## 1. 背景与目标

PandaClaw 当前是单文件单体服务（`service.ts` 1386 行）：会议核心（convene/stage/tally/adjourn 等 9 方法）与复审闭环（18 方法 + 8 私有辅助 ≈ 540 行）混居一个类。经 grilling 拷问，确立三个目标：

1. **模块化**：复审从会议核心解耦为独立领域类，边界成为代码事实（单插件内拆分为先）。
2. **依赖可替换**：对 dsh 底座（agents/tools/team）的依赖收敛到装配层适配（`AgentHost`），业务层只依赖自有接口——符合 dsh「万物皆插件」理念，底座/官方工具可替换。
3. **一键预设终局（B′）**：PandaClaw 最终作为 dsh agent preset 一键部署 + 宿主插件双层形态（记入后续，不在本轮）。

### 3.1 接口形态

```ts
// host.ts
export interface AgentHost {
  /** 装备工具到一个会话（按 preset 匹配）；返回撤装 disposer. */
  equip(agent: Agent, factories: readonly ToolFactory[]): () => void
  /** 创建替身会话（审查/监督）；返回可销毁 handle. */
  createStandin(kind: 'reviewer' | 'supervisor', docId: string, opts: {
    preset: string
    brief: string
    payload?: Readonly<Record<string, unknown>>   // 结构化审查包（reviewer）
  }): Promise<{ dispose(): Promise<void> }>
  /** 枚举现存替身（启动清理/恢复用）. */
  listStandins(): readonly { sessionId: string; kind: 'reviewer' | 'supervisor'; docId: string }[]
  /** 注册装备策略（按 preset/leads 匹配 + 工厂）；机制/策略分离（Q22-A）. */
```

## 4. 实现步骤（分阶段、每步可验证）

### 阶段 1：store.ts 抽取（域存取下沉）

1. 新建 `src/store.ts`：`PandaClawStore` 接口 + `makeStore(opening: Promise<Domain>)` 实现（持域句柄）。

3. service.ts 构造改收 `store`（不再直接持 `opening`），会议核心方法改调 store。
4. **验证**：typecheck + smoke 全绿（行为不变）。

### 阶段 2：review.ts 抽取（复审领域类）

触发信号（Q14-A）：复审逻辑又要大改 / 他人复用复审 / 多插件共享域。

依赖契约（Q18-A，需 ADR 记录）：
- PandaClaw 对宿主要求：`agents`（替身 spawn）、`storageDomain`（域）、`tools`/`systemPrompt`/`session`（工具装备）、`sessionProjections`（投影）；
- 对底座 team 要求：产生 Agent 会话 + agent/created 事件 + 子代理作用域工具注册（AgentHost 适配器实现）；
- 替换实现须满足上述契约（换 cordis.yml 行 + 换 AgentHost 实现）。
